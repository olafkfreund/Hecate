# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1, in full. The text is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

The short version: be decent to each other. Disagree with ideas as sharply as
you like — this project's own decision records are full of options argued down —
but not with people.

## Reporting

Report unacceptable behaviour privately through GitHub, using
[report abuse](https://github.com/contact/report-abuse) or by contacting the
repository maintainer. Reports are handled confidentially and the reporter is
not identified to the person reported.

Enforcement follows the Covenant's escalation ladder: correction, warning,
temporary ban, permanent ban.
